# 🧪 DESAFIO 1 — Conversor de Temperatura

## Enunciado
Crie uma classe chamada `ConversorTemperatura` que possui um método chamado `CelsiusParaFahrenheit`.

- O método recebe um valor em graus Celsius (tipo `double`).
- O método retorna o valor convertido para Fahrenheit (tipo `double`).

**Fórmula:** `F = C * 1.8 + 32`

## Como entregar
1. Implemente a classe no arquivo `ConversorTemperatura.cs`.
2. **NÃO altere** o arquivo `Program.cs`.
3. Teste localmente com `dotnet run` e confirme que o output bate com o esperado.
4. Faça commit e push no seu fork.
5. Me mande o link do seu fork.

## Output Esperado
```text
0°C = 32°F
100°C = 212°F
36,6°C = 97,88°F
```

## O que será avaliado
- Você criou a classe com o nome correto?
- O método recebe `double` e retorna `double`?
- Você usou `return` pra devolver o valor (e não `Console.WriteLine` dentro do método)?
- A fórmula está correta?
